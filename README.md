# 🛒 GALAZON – E-Commerce Web Application

GALAZON is a dynamic, Amazon-inspired e-commerce web application built to demonstrate core **front-end and JavaScript-based interactivity**. The project focuses on real-world shopping features such as product browsing, search functionality, and cart management using **localStorage**, making it a strong foundation-level e-commerce system.

---

## 🚀 Features

- 🏠 Responsive home page with product listings  
- 🔍 Dynamic product search functionality  
- 📄 Product listing & detail pages  
- 🛒 Add-to-cart functionality using browser localStorage  
- ➕ Increase / decrease item quantity  
- ❌ Remove items from cart  
- 💰 Real-time cart price calculation  
- 📱 User-friendly and responsive UI  

---



- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Storage:** Browser LocalStorage
- **Tools:** VS Code, GitHub
- **Version Control:** Git

## ⚙️ How It Works

1. Products are dynamically rendered using JavaScript.
2. Users can search products in real-time.
3. Selected products are stored in `localStorage`.
4. Cart data persists even after page refresh.
5. Total price updates automatically based on cart changes.
